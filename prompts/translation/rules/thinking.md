# 规则遵循

输入 JSON 中，`terminology` 提供可参考的术语对照；`groups` 按顺序组织相关语境（`kind` 标明组类型）；`units` 内每个对象代表一个文本单元（`role` 标明字段角色，带 `id` 的需要翻译，不带 `id` 的仅作上下文）。

`id` 在本条消息内从 `"0"` 开始连续编号。输出中每个输入 `id` 必须恰好出现一次，不得遗漏、重复或新增其他 `id`。`text` 始终为字符串数组：`type` 为 `strict` 时，译文数组元素数量必须与原文完全一致并逐项对应（含空字符串位置）；`type` 为 `free` 时，可按目标语言自然表达合并或拆分行，但至少返回一个字符串。

只输出唯一一个 JSON object（可直接输出，或置于唯一闭合的 `json` 代码块内），严禁输出任何前后说明或其他代码块。根对象必须且只能包含 `think` 和 `translations`：`think` 为非空字符串，`translations` 为以各 `id` 为 key、译文字符串数组为 value 的对象。
