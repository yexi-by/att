# A.T.T MZ v0.1.15：0.x 最终维护版

很抱歉，由于我经验不足，0.x 的整体设计逐渐偏离了项目初衷，翻译流程还出现了错误阻断、重复检查和性能下降等严重问题，影响了正常使用。

经过复盘，我决定停止继续修补现有架构，将项目推倒重做，全力投入 1.0 的开发。

v0.1.15 是 0.x 的最后一个稳定维护版本，主要修复影响翻译、恢复和写回的严重问题，作为 1.0 发布前的过渡版本。之后 0.x 原则上只处理致命问题，不再增加新功能。

给大家带来的困扰，再次表示抱歉。也感谢所有提供反馈和帮助测试的用户。

## 主要修复

- 修复结构化 `\\NW[...]` 规则已正确保护但仍被普通候选扫描阻止的问题。
- 修复翻译错误率停止后仍继续发送模型请求、重试次数叠加和超时结果丢失。
- 修复写回检查失败后游戏文件可能已经被部分修改的问题。
- 增加上下文安全的译文复用、附加源语言、工作区身份绑定和结构化失败报告。
- 合并重复的 AST、Note、placeholder 和质量扫描，限制 Rust 工作线程并复用线程池。
- Windows 发行包改为固定 CPython 和 copy-only 依赖；标准库、项目与依赖模块使用稳定相对路径编译为相邻 `UNCHECKED_HASH` pyc，发行 ZIP 不再包含 Python/C/C++/Tcl 等源码或开发资产，也不在用户电脑上执行 PEX/scie 解包、建链接或缓存初始化。

## 升级说明

- 数据库 schema 已更新到 12。发布准备阶段指定的 v11 数据库已经通过不可覆盖备份、同目录 v12 临时数据库、完整性与行数核验完成一次性迁移；临时迁移器已按约定删除。程序不会在普通运行中自动迁移其他旧数据库，未纳入本次迁移的旧库需要重新注册游戏。
- 旧工作区 manifest 不再接受，请重新执行 `prepare-agent-workspace`。已导入数据库的术语和规则不会因此丢失。
- 追加源语言必须在注册时使用 `--additional-source-language` 显式声明。

## 发行包验证

本版本只发布 Windows x86_64。创建 tag 前可对完整 commit SHA 运行不具备发布能力的 `release preflight`；它与正式 `release` 共用同一门禁脚本。GitHub Actions 会验证提交或 tag、Python/Rust 版本、全量测试、sourceless pyc、两次独立构建哈希和普通 Windows 用户解压后冒烟。

正式发布把只读验证/构建与可写发布拆成两个 job；发布 job 只下载同次 artifact，以 verify job 独立传入的四个 SHA-256、release manifest 及远端 tag peeled commit 复核后上传，不会再次构建。构建输出严格限制为工作区普通直接子目录，递归删除拒绝任意后代 reparse point；普通用户冒烟逐命令验证 stdout、stderr、退出码和真实 Win32 1314 权限拒绝。下载后可使用随 Release 提供的 `SHA256SUMS.txt` 校验文件。

## 已知限制

- v0.1.15 不提供 Linux 发行包。
- 数据库和工作区不提供运行时旧格式兼容；这是为了避免继续保留无法证明正确的历史路径。
